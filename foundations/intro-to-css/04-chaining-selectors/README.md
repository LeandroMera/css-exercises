# Chaining Selectors

Credits for the images in this exercise go to [Katho Mutodo](https://linktr.ee/photobykatho_) and [Andrea Piacquadio](https://www.pexels.com/@olly?utm_content=attributionCopyText&utm_medium=referral&utm_source=pexels).


With this exercise, we've provided you with a complete HTML file and a CSS file to work with. The purpose of this exercise is to focus on understanding how to chain different selectors, rather than solely adding attributes.

We have two images for you to style, each with two class names, where one of the class names is shared. The goal here is to chain the selectors for both elements, so that each have a unique style applied, despite using a shared class selector. For example, you want an element that has both X and Y to have one set of styles, while an element with X and Z has a completely different set of styles. We included the original images as well, so that you can see how the styles you will be adding look in comparison, so do not add any styles to them.

The properties you need to add to each element are:

- Make the element with both the `avatar` and `proportioned` classes 300 pixels wide. We want it to automatically retain its original square proportions, so don't hardcode in a pixel value for its height.
- Make the element with both the `avatar` and `distorted` classes 200 pixels wide, then make its height twice as big as its width (here you should hardcode in a pixel value).

# Encadenamiento de Selectores

Los créditos de las imágenes de este ejercicio son para [Katho Mutodo](https://linktr.ee/photobykatho_) y [Andrea Piacquadio](https://www.pexels.com/@olly?utm_content=attributionCopyText&utm_medium=referral&utm_source=pexels).

En este ejercicio, te proporcionamos un archivo HTML completo y un archivo CSS para que trabajes con ellos. El objetivo es que comprendas cómo encadenar diferentes selectores, en lugar de simplemente añadir atributos.

Tenemos dos imágenes para que les apliques estilos, cada una con dos nombres de clase, uno de los cuales es compartido. El objetivo es encadenar los selectores para ambos elementos, de modo que cada uno tenga un estilo único, a pesar de usar un selector de clase compartido. Por ejemplo, quieres que un elemento con X e Y tenga un conjunto de estilos, mientras que un elemento con X y Z tenga un conjunto de estilos completamente diferente. También incluimos las imágenes originales para que puedas ver cómo se ven los estilos que añadirás en comparación; por lo tanto, no les añadas ningún estilo.

Las propiedades que debes añadir a cada elemento son:

- Haz que el elemento con las clases `avatar` y `proportioned` tenga un ancho de 300 píxeles. Queremos que conserve automáticamente sus proporciones cuadradas originales, así que no introduzcas un valor en píxeles para su altura.

- Haz que el elemento con las clases `avatar` y `distorted` tenga un ancho de 200 píxeles y que su altura sea el doble de su ancho (aquí sí debes introducir un valor en píxeles).
